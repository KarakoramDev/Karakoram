# Karakoram brand assets

The Karakoram mark ("Ridge K"): the K2 pyramid with a K carved into it as ridgelines; the summit cap carries the accent colour.

| File | Use |
|---|---|
| `karakoram-lockup-light.svg` / `karakoram-lockup-dark.svg` | Mark + wordmark for light / dark backgrounds |
| `karakoram-mark.svg` | Mark only, single colour (`currentColor`) |
| `karakoram-mark-color.svg` | Mark with teal summit cap, body in `currentColor` |
| `karakoram-favicon.svg` | Favicon with light/dark handling |
| `karakoram-icon-512.png` | Square icon (avatars, app icons) |
| `karakoram-social-card.png` | 1200×630 social preview image |

Colours: ink `#141b21` / `#e6ebee` (light / dark), teal `#0b6b74` / glacier `#5fd0d8`. The wordmark is Instrument Sans 600 (SIL Open Font License), converted to paths.
